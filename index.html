Place-Anything-Anywhere: A Lightweight Robot Agnostic Goal Generator

Overview of Place-Anything-Anywhere, a language-guided 6-DoF object placement framework. Scene RGBD, object RGBD, and text instructions are processed through perception and language-conditioning modules to extract semantic, spatial, and relational embeddings. These representations are fused using a Q- Former reasoning module, and the resulting latent representation is used by the placement head to predict the final 6-DoF object placement within the reconstructed scene.

Abstract

While natural language has emerged as a powerful interface for robotic manipulation, translating open-vocabulary instructions into precise physical ac- tions remains a persistent challenge. Recent trends often favor end-to-end Vision- Language-Action (VLA) systems that directly map visual and textual inputs to continuous robot trajectories. While highly capable, these architectures can incur substantial computational costs. In this work, we argue that for fundamental rigid- body manipulation—such as everyday pick-and-place and scene rearrangement- simply establishing the accurate geometric goal pose of the object prior to execu- tion is enough for task completion.
To this end, we present a lightweight framework designed specifically for language-conditioned object relocation. Our system takes a source object RGB- D, a target RGB-D scene, and a natural language instruction, and outputs the goal positioning of the object. Unlike large VLA systems, our approach focuses strictly on multimodal geometric reasoning and goal generation. By treating ob- ject grounding and segmentation as modular front-end components, our architec- ture efficiently fuses language intent with 3D scene structure to predict precise manipulation goals without requiring massive parameter counts. This provides a scalable, robot-agnostic interface for downstream motion planning, offering a highly robust and computationally accessible foundation for real-world rearrange- ment tasks.

How Place-Anything-Anywhere Works

  1. Multi-Modal Object and Scene Encoding
    The first stage of our pipeline maps continuous RGB-D observations into discrete multimodal tokens for the source object and target scene. Both inputs are processed using parallel encoders composed of a frozen DINOv2 backbone for visual semantics and PointNet++ for local geometry.
  2. Language Conditioning
    To convert the natural language instruction L into actionable geometric constraints, we factorize the language into three complementary streams
    • Grounded sequence features: A frozen T5 encoder provides contextualized language features, while a lightweight LLM extracts the source object, anchor objects, and relation spans. Instruction tokens attend to the contextualized scene representation T_scene to form a grounded language memory T_lang ∈ R^ N_L × D (where N_L is the instruction length). Simultaneously, the A extracted anchor objects are grounded to yield anchor tokens T_anchor ∈ R^A×D .
    • Continuous relation conditioning & discrete spatial embeddings: Relation spans are aggregated into a continuous relation vector R_cond ∈ R^ D and anchor-specific embeddings R_rel ∈ R^ A×D . These provide both global and structural spatial priors for subsequent Q-Former reasoning. Together, T_lang , R_cond , and R_rel isolate semantic identity from geometric intent to enable language- guided spatial reasoning.
  3. Q-Former
    After geometric parsing and language grounding, the network must integrate scene geometry, object context, and spatial intent into a compact representation suitable for placement prediction. To this end, we employ a Relational Querying Transformer (Q-Former) bottleneck that compresses multimodal context into a latent action representation.
  4. Placement Prediction Head
    The final stage of Place-Anything-Anywhere maps the distilled action latent z into an actionable placement transformation. Rather than generating pixel-level futures, which often suffer from ge- ometric distortion and scale inconsistencies, we formulate goal generation as a continuous pose prediction problem in 3D space. The latent vector z is processed by an MLP translation head that predicts a 3D displacement vector ∆t ∈ R^3 . To promote spatial generalization across diverse scenes, the network predicts an anchor-relative offset rather than an absolute world coordinate.

Language-conditioned relational reasoning: The instruction is decomposed into grounded lan- guage features, a continuous relation prior, and discrete spatial relation embeddings. The relation prior condi- tions the learnable Q-Former queries, while the relation embeddings are fused with grounded anchor tokens. A two-stage Q-Former first reasons over visual-geometric context and then grounded language memory, produc- ing a compact latent bottleneck used for placement prediction.
